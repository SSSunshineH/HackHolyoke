# Dishwashing Room Game

🏆 HackHolyoke 2025 Winning Project

This is a Java-based game developed using the GaFr framework by Professor James McCauley (Murphy). The game simulates the daily work experience of student workers in the dishwashing room at Mount Holyoke College.

All visuals were either designed by our team or captured on campus in the dining facilities.

A short gameplay demo is included in the repository. Due to GitHub file size limitations, the video may not display directly on GitHub.
